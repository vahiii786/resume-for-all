# 🚀 Smart AI Resume Hub

An all-in-one **Streamlit career assistant** that helps users analyze, build, and optimize resumes while preparing for job applications.

## ✨ Features

* 📊 **Resume Analyzer** – Match resume with Job Description and find missing keywords.
* ✏️ **Resume Builder** – Create and preview ATS-friendly resumes with multiple themes.
* ✨ **AI Bullet Rewriter** – Improve basic resume statements.
* 🎯 **ATS Keyword & Red Flag Detector** – Find missing keywords and common resume clichés.
* 💰 **Salary Predictor** – Estimate salary range based on experience requirements.
* ✉️ **HR Outreach Generator** – Generate LinkedIn messages and cold emails.
* 🎤 **Mock Interview** – Practice role-specific interview questions.

## 🛠️ Tech Stack

**Python · Streamlit · PyPDF · PyPDF2 · python-docx · HTML/CSS**

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📄 Supported Files

* PDF
* DOCX
* TXT
